# El Gringo J&M

Sitio web estatico de la polleria, listo para abrir y editar en VS Code.

## Estructura

| Ruta | Contenido |
| --- | --- |
| `index.html` | Estructura de la pagina. |
| `css/styles.css` | Estilos, colores y diseno responsive. |
| `js/data/menu-data.js` | Productos, precios, categorias y fotos de cada categoria. |
| `js/app.js` | Carrito, delivery, tapers y envio del pedido a WhatsApp. |
| `assets/` | Logos, fotos editables y archivos de referencia. |

## Cambios frecuentes

- Cambiar un precio o producto: edita `js/data/menu-data.js`.
- Cambiar una foto de categoria: reemplaza el archivo equivalente dentro de `assets/images/categories/`.
- Cambiar foto de portada: reemplaza `assets/images/hero-pollo-a-la-brasa.jpg`.
- Cambiar logo: reemplaza `assets/branding/logo-el-gringo.jpeg`.

Abre `index.html` en el navegador para visualizar el sitio.
