# Assets

## `branding/`

Contiene el logo usado por el sitio. Conserva el nombre `logo-el-gringo.jpeg` al reemplazarlo.

## `images/`

Contiene las fotos de portada y de la seccion Nosotros.

## `images/categories/`

Contiene una imagen para cada categoria de la carta. Puedes reemplazarlas sin cambiar el codigo si conservas sus nombres y extensiones: `chaufas.jpg`, `combos.jpg`, `pollos-a-la-brasa.jpg`, `saltados.jpg`, `salchipapas.jpg`, `sopas.jpg`, `especiales.jpg` y `bebidas.jpg`.

## `references/`

Guarda la carta y logo originales como referencia. No son usados directamente por la web.

Usa fotos JPG horizontales de 1000 px de ancho o mas para mejores resultados.
